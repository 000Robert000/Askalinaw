Our trade-off, and the gap we'd fix first

We optimised for Operational Excellence and Security, because that is what an ops team is judged on and both are cheap to do well. We deliberately accepted weaker Reliability: one server in one Availability Zone, because a second server or a managed database would roughly double the cost of a student project.

Gap we would fix first: move MongoDB off the server (Amazon DocumentDB or MongoDB Atlas free tier) and put the app behind an Auto Scaling group of one. A dead server would then come back by itself in minutes instead of needing a manual restore.
