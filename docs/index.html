Askalinaw: a campus help desk that we run properly

Presentation video (5–8 min), presented by Robert Santiago and Ivan Ray Dequiros.

What the system does

Askalinaw is a chat assistant for students of Kalinaw University, a university we invented for this project. Students type questions like "Where do I pay my tuition?" or "I lost my ID, what do I do?" and the assistant answers from a short handbook of campus offices, enrollment dates, fees and rules. It only gives information. It never decides anything about a person, such as grades, scholarships or discipline.

It is built on LibreChat, a free, open-source ChatGPT-style app, which we renamed, re-coloured and filled with our own content. The answers come from Google's Gemini model (free tier). Everything else (the server, database backups, file storage, secrets, monitoring and alerts) runs in Amazon Web Services (AWS), and that is what this project is really about.

Live system: https://32-236-2-242.sslip.io

What was wrong with how it was run

Out of the box, LibreChat is a program you start on one computer and hope for the best. There is no warning when it breaks, no copy of the data if the disk dies, secrets sit in a plain text file, and logs grow until the disk fills up. See Baseline.

What we changed

  • We can see it: a dashboard, 10 alarms that email both of us, and a log line for every request.
  • We can recover it: a nightly database backup to S3, versioned content, and a restore we actually tested (31 seconds).
  • It's locked down: MFA, own logins, no SSH port, secrets in Parameter Store, least-privilege permissions, encrypted disk.
  • It looks after itself: two automations (nightly backup, and a health check every 5 minutes that also tests an AI answer every hour) that run with nobody touching them.
  • We broke it on purpose: filled the disk, got alerted in 13 minutes, fixed it, found the root cause, and added prevention.
