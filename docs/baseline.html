Baseline: the environment before we touched it

Our starting point was stock LibreChat as published, set up the way its quick-start describes: Docker Compose on a laptop, reachable only at localhost:3080. We did not keep a local run of it; screenshot E-05 shows the stock interface from the official project page, captured 20 Nov 2026. This is what "running it" looked like before the project.

AreaBaseline (stock LibreChat quick start)
Where it runsOne laptop, http://localhost:3080, no HTTPS, gone when the laptop sleeps.
MonitoringNone. The only way to know it was down was to open it.
LogsDocker container logs with no size limit; LibreChat log files on local disk.
BackupsNone. The MongoDB data folder lives only on that disk.
SecretsAll keys in a plain-text .env file next to the code.
AccessAnyone who can reach the port can register.
AutomationNone.
ContentNone. A general chatbot with no knowledge of our domain.

CostPHP 0 (laptop), but not available to anyone else.

Security problems we listed at the start

  1. Secrets in a plain-text file that is easy to commit to git by accident.
  2. No HTTPS: passwords would cross the network in clear text.
  3. The obvious way to get a shell on a cloud server is SSH on port 22 open to the internet.
  4. Class AWS account: risk of shared logins without MFA.
  5. No audit trail of who changed what.
  6. Unencrypted disk by default on older setups.

The fixes are in the before-and-after table on Security.
